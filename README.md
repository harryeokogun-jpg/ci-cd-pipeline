# Automated Portfolio Website CI/CD
A modern, simple and lightweight portfolio website to demonstrate continuous integration and continuous deployment [CI/CD] automated workflows with GitHub actions and GitHub pages.

# Technologies
- HTML and CSS
- Node.js built in test runner
- Git and GitHub
- GitHub Actions
- GitHub pages

# Automated pipeline
When code is pushed to the main branch, GitHub actions runs the automated tests. If the tests pass, the website is deployed

## Run tests locally:
bash
 npm test
